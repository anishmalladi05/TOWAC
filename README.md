# TOWAC
Description
TOWAC (Table Organizer With All Colors) is a magnetic, 3D printed table organizer system inspired by Scott Yu-Jan's WORBY and Zach Freedman's GridFinity. While GridFinity is perfect for a workshop, it is not exactly what I would want in my home. While it is customizable, the default square plate underneath ruins the aesthetic (for me), so I created TOWAC, heavily inspired by Neo-Plasticism and WORBY (you can see it in the naming). It combines the art and vibes of WORBY with the customizability and utility of GridFinity. I would like to say that all work is mine, I did not edit or download any other files for this project, I created this project from scratch, and the only thing I borrowed from others is inspiration. TOWAC uses base boxes as structure with inserts for color. This is so you can have a neutral base color and different accent colors. This allows for quicker customizability and allows the model to not use any press fit or snap fit joints, allowing the model to be scaled freely and to be printed on any printer. This contributes to my goal of making TOWAC truly customizable, not just bound to the arbitrary guidelines that I have set in place. The inserts also allow you to customize it with ANY color. I have included paper printouts that you can use to cut out and insert in place, allowing you to even import designs. Use my guide and the included SVG to print out the paper making sure to size it correctly, or if you don't want to resize, feel free to use my included PDF on A4 Paper in blue. The SVG is in the documentation.
